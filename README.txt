MiniAI Chrome — مدل زبانی مولد بسیار کوچک

محتویات:
- index.html: رابط چت و موتور اجرای مدل در JavaScript
- model.json: وزن‌های واقعی آموزش‌دیده و واژگان نویسه‌ای
- README.txt: این راهنما

منبع وزن‌ها:
وزن‌های model.json در همین ساخت پروژه از صفر آموزش داده شده‌اند؛ وزن‌های مدل دیگری کپی نشده‌اند. معماری یک Elman RNN نویسه‌محور با embedding، حالت پنهان tanh و خروجی softmax است. آموزش روی نمونه‌متن کوتاه فارسی/انگلیسی همراه پروژه، با 900 گام بهینه‌سازی انجام شده است.

محدودیت مهم:
این یک مدل مولد عصبی واقعی در مقیاس آموزشی است، اما LLM عمومی نیست. نمونه‌متن کم است، بنابراین خروجی ممکن است نامنسجم یا تکراری باشد و توانایی استدلال/دانش عمومی ندارد. هیچ پاسخ آماده یا قانون شرطی برای انتخاب پاسخ در برنامه قرار نگرفته؛ متن به‌صورت نویسه‌به‌نویسه با نمونه‌گیری از خروجی شبکه تولید می‌شود.

اجرا:
بهتر است پوشه را روی GitHub Pages یا هر میزبان استاتیک HTTPS قرار بده و index.html را در Chrome باز کن. اگر می‌خواهی کاملاً آفلاین باشد، یک بار فایل‌ها را دانلود کن و از یک سرور محلی استاتیک استفاده کن؛ fetch روی file:// در بعضی نسخه‌های Chrome محدود است. برای GitHub Pages، فایل‌ها را در ریشه مخزن قرار بده.

کنترل‌ها:
- طول خروجی: تعداد نویسه‌های تولیدی
- تنوع: دمای نمونه‌گیری؛ بالاتر یعنی خروجی متنوع‌تر و معمولاً کم‌ثبات‌تر

اندازه فایل model.json زیر 10 MB است.
