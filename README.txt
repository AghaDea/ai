NOVA — Local AI
================
چت‌بات هوش مصنوعی محلی برای Google Chrome (دسکتاپ و اندروید)
نسخه: 1.2
مدل: Falcon-H1-Tiny-90M-Instruct (GGUF IQ2_M ≈ ۱۲٫۷ مگابایت) — فقط فایل محلی
موتور: wllama v3.8.1 (llama.cpp → WebAssembly)

────────────────────────────────────────
ساختار پروژه پس از استخراج
────────────────────────────────────────

  NOVA_Chrome_Local_AI/
  ├── index.html
  ├── README.txt
  ├── LICENSES.txt
  ├── models/          ← پوشه خالی؛ فایل مدل را خودتان اینجا بگذارید
  │   └── (اینجا قرار دهید:)
  │       Falcon-H1-Tiny-90M-Instruct-IQ2_M.gguf
  └── assets/

────────────────────────────────────────
۱. قرار دادن فایل مدل
────────────────────────────────────────
فایل مدل داخل ZIP نیست (به‌خاطر حجم). خودتان دانلود کنید و داخل models/ بگذارید:

  لینک مستقیم:
  https://huggingface.co/tiiuae/Falcon-H1-Tiny-90M-Instruct-GGUF/resolve/main/Falcon-H1-Tiny-90M-Instruct-IQ2_M.gguf

  نام فایل باید دقیقاً این باشد:
  Falcon-H1-Tiny-90M-Instruct-IQ2_M.gguf

  مسیر نهایی:
  NOVA_Chrome_Local_AI/models/Falcon-H1-Tiny-90M-Instruct-IQ2_M.gguf

────────────────────────────────────────
۲. اجرای پروژه
────────────────────────────────────────
حتماً با سرور محلی اجرا کنید (نه باز کردن مستقیم file://):

  cd NOVA_Chrome_Local_AI
  python3 -m http.server 8080

سپس در Chrome:
  http://localhost:8080

روی اندروید / انتشار عمومی:
  پروژه را روی GitHub Pages یا هر هاست استاتیک بگذارید
  و فایل مدل را هم در models/ آپلود کنید.

────────────────────────────────────────
۳. بارگذاری خودکار
────────────────────────────────────────
با باز شدن صفحه، برنامه به‌صورت خودکار به مدل محلی وصل می‌شود.

- اگر فایل پیدا شود → بارگذاری و آماده شدن چت
- اگر فایل نباشد یا خطا رخ دهد → پیام خطای واضح + دکمه «تلاش مجدد»

هیچ دانلودی از اینترنت برای وزن‌های مدل انجام نمی‌شود.
(فقط اسکریپت موتور wllama از CDN لود می‌شود.)

────────────────────────────────────────
۴. تشخیص آماده‌بودن
────────────────────────────────────────
- نقطه وضعیت سبز + متن «مدل آماده است»
- کادر پیام و دکمه ارسال فعال می‌شوند
- پیام سیستمی تأیید بارگذاری ظاهر می‌شود

────────────────────────────────────────
۵. در صورت خطا
────────────────────────────────────────
پیام خطا مسیر دقیق مورد انتظار را نشان می‌دهد.

بررسی کنید:
  • فایل با نام درست داخل models/ باشد
  • پروژه با http.server یا هاست اجرا شود (نه file://)
  • حافظه دستگاه کافی باشد
  • Chrome به‌روز باشد

سپس روی «تلاش مجدد» کلیک کنید یا صفحه را رفرش کنید.

────────────────────────────────────────
۶. مکالمه، خروجی و پاک کردن
────────────────────────────────────────
- Enter = ارسال | Shift+Enter = خط جدید
- تاریخچه در localStorage ذخیره می‌شود
- خروجی JSON و TXT
- پاک کردن مکالمه با تأیید

────────────────────────────────────────
۷. اینترنت و آفلاین
────────────────────────────────────────
نیاز به اینترنت:
  • فقط برای لود اولیه اسکریپت wllama از CDN (یک‌بار)

وزن مدل:
  • کاملاً محلی از پوشه models/

تولید پاسخ:
  • بدون اینترنت

────────────────────────────────────────
۸. محدودیت‌ها (صادقانه)
────────────────────────────────────────
