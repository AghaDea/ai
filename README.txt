NOVA — Local AI
================
چت‌بات هوش مصنوعی محلی برای Google Chrome (دسکتاپ و اندروید)
نسخه: 1.1
مدل: Falcon-H1-Tiny-90M-Instruct (GGUF IQ2_M ≈ ۱۲٫۷ مگابایت) — داخل پروژه
موتور استنتاج: wllama v3.8.1 (llama.cpp کامپایل‌شده به WebAssembly)

────────────────────────────────────────
۱. استخراج ZIP
────────────────────────────────────────
فایل ZIP را در هر پوشه‌ای استخراج کنید. ساختار باید شبیه این باشد:

  NOVA_Chrome_Local_AI/
  ├── index.html
  ├── README.txt
  ├── LICENSES.txt
  ├── models/
  │   └── Falcon-H1-Tiny-90M-Instruct-IQ2_M.gguf   ← وزن‌های مدل (~۱۲٫۷ مگابایت)
  └── assets/

────────────────────────────────────────
۲. استقرار روی GitHub Pages (پیشنهادی)
────────────────────────────────────────
۱. یک مخزن جدید در GitHub بسازید (مثلاً nova-local-ai).
۲. محتویات پوشه NOVA_Chrome_Local_AI را در ریشه مخزن آپلود کنید
   (فایل مدل حدود ۱۳ مگابایت است؛ GitHub فایل‌های زیر ۱۰۰ مگابایت را می‌پذیرد).
۳. در Settings → Pages، Source را روی branch main و پوشه / (root) بگذارید.
۴. پس از چند دقیقه آدرس https://YOUR_USERNAME.github.io/nova-local-ai/ در دسترس است.
۵. حتماً از HTTPS استفاده کنید (GitHub Pages به‌صورت پیش‌فرض HTTPS می‌دهد).

نکته: برای عملکرد کامل WebAssembly چندنخی، سرور باید هدرهای زیر را بفرستد
(در GitHub Pages معمولاً مشکل خاصی ایجاد نمی‌کند؛ در سرور شخصی اضافه کنید):
  Cross-Origin-Opener-Policy: same-origin
  Cross-Origin-Embedder-Policy: require-corp

────────────────────────────────────────
۳. باز کردن در Google Chrome
────────────────────────────────────────
- روش آسان: فایل index.html را مستقیماً در Chrome باز کنید (file://).
  در بسیاری از موارد کار می‌کند، اما بعضی قابلیت‌های WASM ممکن است محدود شوند.
- روش توصیه‌شده: از یک سرور محلی ساده استفاده کنید:
    • در پوشه پروژه: python3 -m http.server 8080
    • سپس در Chrome بروید به: http://localhost:8080
- روی اندروید: همان آدرس GitHub Pages یا سرور محلی را در Chrome اندروید باز کنید.

────────────────────────────────────────
۴. بارگیری مدل
────────────────────────────────────────
۱. صفحه را باز کنید.
۲. در پنل کناری (یا پایین در موبایل) روی دکمه «بارگیری مدل» کلیک کنید.
۳. برنامه ابتدا فایل محلی models/Falcon-H1-Tiny-90M-Instruct-IQ2_M.gguf را بارگذاری می‌کند.
۴. اگر فایل محلی در دسترس نباشد (مثلاً مسیر اشتباه یا file:// محدود)، به‌صورت خودکار
   از Hugging Face دانلود می‌کند.
۵. نوار پیشرفت واقعی درصد و حجم را نشان می‌دهد.
۶. پس از اتمام، وضعیت به «مدل آماده است» تغییر می‌کند و ورودی چت فعال می‌شود.

لینک مدل اصلی (در صورت نیاز به دانلود دستی):
https://huggingface.co/tiiuae/Falcon-H1-Tiny-90M-Instruct-GGUF/resolve/main/Falcon-H1-Tiny-90M-Instruct-IQ2_M.gguf

صفحه مدل:
https://huggingface.co/tiiuae/Falcon-H1-Tiny-90M-Instruct-GGUF

────────────────────────────────────────
۵. تشخیص آماده‌بودن موتور و مدل
────────────────────────────────────────
- نقطه وضعیت در بالای صفحه سبز شود و متن «مدل آماده است» نمایش داده شود.
- دکمه ارسال و کادر متن فعال شوند.
- پیام سیستمی «مدل با موفقیت بارگذاری شد» ظاهر شود.

اگر خطا رخ داد، پیام خطا در پنجره چت نمایش داده می‌شود و دکمه «تلاش مجدد» فعال می‌ماند.

────────────────────────────────────────
۶. ارسال پیام آزمایشی
────────────────────────────────────────
پس از آماده‌شدن مدل:
  • متنی به انگلیسی بنویسید (مثلاً: Hello, who are you?)
  • Enter بزنید یا روی دکمه ارسال کلیک کنید.
  • پاسخ مدل به‌صورت تدریجی (در صورت پشتیبانی موتور) یا یکجا ظاهر می‌شود.

توجه: مدل عمدتاً روی انگلیسی آموزش دیده. پاسخ فارسی ممکن است ضعیف، ناقص یا اشتباه باشد.

────────────────────────────────────────
۷. در صورت شکست بارگذاری یا تولید پاسخ
────────────────────────────────────────
• مطمئن شوید فایل models/Falcon-H1-Tiny-90M-Instruct-IQ2_M.gguf وجود دارد.
• از سرور محلی (python -m http.server) یا GitHub Pages استفاده کنید؛
  باز کردن مستقیم file:// گاهی برای WASM محدودیت دارد.
• حافظه دستگاه را آزاد کنید.
• از Chrome به‌روز استفاده کنید.
• صفحه را رفرش کرده و دوباره «بارگیری مدل» را بزنید.

────────────────────────────────────────
۸. خروجی گرفتن و پاک کردن تاریخچه
────────────────────────────────────────
• دکمه «خروجی JSON» یا «خروجی TXT» فایل مکالمه را دانلود می‌کند.
• دکمه «پاک کردن مکالمه» با تأیید کاربر، تاریخچه را از صفحه و localStorage پاک می‌کند.
• تاریخچه به‌صورت خودکار در localStorage مرورگر ذخیره و پس از رفرش بازیابی می‌شود.

────────────────────────────────────────
۹. نیاز به اینترنت و حالت آفلاین
────────────────────────────────────────
نیاز به اینترنت:
  - اولین بار: دانلود اسکریپت‌های wllama از CDN (jsDelivr) — چند صد کیلوبایت تا چند مگابایت
  - وزن‌های مدل داخل پروژه هستند و از فایل محلی خوانده می‌شوند (نیازی به دانلود مدل نیست)

پس از بارگذاری موفق موتور و مدل:
  - تولید پاسخ نیاز به اینترنت ندارد.
  - اگر کش مرورگر پاک نشود، دفعات بعدی سریع‌تر خواهد بود.

────────────────────────────────────────
۱۰. محدودیت‌های کیفیت، زبان، حافظه و سرعت
────────────────────────────────────────
• مدل فقط ۹۰ میلیون پارامتر دارد — بسیار کوچک‌تر از مدل‌های تجاری.
• عمدتاً انگلیسی‌آموزش‌دیده است؛ فارسی ضعیف است و ممکن است توهم یا پاسخ بی‌ربط بدهد.
• IQ2_M quant برای صرفه‌جویی حجم انتخاب شده؛ کیفیت پایین‌تر از quantهای بالاتر است.
• زمینه مکالمه محدود نگه داشته شده (حدود ۸ پیام اخیر) تا حافظه و سرعت حفظ شود.
• سرعت روی موبایل و CPU ضعیف کندتر است.
• این پروژه جایگزینی برای ChatGPT یا مدل‌های بزرگ نیست؛ یک آزمایش واقعی اجرای مدل
  از پیش‌آموزش‌دیده داخل مرورگر است.

────────────────────────────────────────
روش اجرای سریع (خلاصه)
────────────────────────────────────────
1. ZIP را استخراج کنید.
2. python3 -m http.server 8080 را در پوشه پروژه اجرا کنید.
3. Chrome را باز کنید → http://localhost:8080
4. «بارگیری مدل» را بزنید و صبر کنید تا سبز شود.
5. پیام آزمایشی بفرستید.
